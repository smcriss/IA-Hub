# IA-Hub

**Python practice, small projects and a path towards automation and AI.**

IA-Hub is where I put my learning into practice: writing code, exploring development tools and building small programs. Over time, I want to connect these foundations into a personal hub for AI tools and everyday automation.

## Knowledge & tools

- **Python:** foundational knowledge developed through Cisco Networking Academy's Python Essentials courses and independent practice.
- **Linux & development tools:** practical experience with Ubuntu, the terminal, VS Code, virtual environments and package management.
- **Git & GitHub:** version control, commits, repository organisation and documentation.

I learn by breaking problems into steps, trying my own solutions and checking the results. This repository documents that process through code.

## Where it is heading

**Foundations → useful programs → automation & AI**

My next steps are to work with files, error handling and data storage, then explore APIs and automation. The long-term goal is to bring different AI tools and workflows together in one personal hub.

IA-Hub is an evolving learning project; the AI integration is a future goal.
